= Contributing to Pons

The maintained contribution guide is link:.github/CONTRIBUTING.md[CONTRIBUTING],
in the location recognised by GitHub. Build with `cargo build --locked` and
run `just check`. Every built-in rule needs positive and negative examples,
an honest evidence class and a counter-condition.

Read link:docs/SCOPE.adoc[scope and priorities] before adding a rule or adapter.
Report defects or proposals at
https://github.com/hyperpolymath/pons-asinorum/issues[the issue tracker].

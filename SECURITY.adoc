= Pons security policy

The maintained reporting policy is link:.github/SECURITY.md[SECURITY], in the
location recognised by GitHub. Pons is a development scanner; a completed scan
is not a security certificate. It neither runs scanned source nor fetches
remote documents during a normal scan.

Optional process adapters are explicit, bounded commands. The offline
container and strict transaction wrapper are documented in
link:build/container/README.adoc[container operation]. The host's SELinux mode
and firewalld settings are never changed automatically.

See link:docs/AUDIT.adoc[the development audit] for verification and remaining
gaps, and link:CHANGELOG.adoc[the changelog] for recorded changes.

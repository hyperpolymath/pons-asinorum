== The core contract

[quote]
____
Never dress a heuristic up as a proof.
____

`Finding`'s private fields enforce two invariants:

* a rule cannot set its own `rule_id`; `RawFinding` has no such field and
  `Engine::scan_files` stamps it from `Rule::id()`;
* `evidence` is re-derived from `tier` on deserialise. The wire type has no
  `evidence` field, so a forged class cannot round-trip.

`SPECULATIVE` is demoted in human, JSON and SARIF output and cannot trigger
`--fail-on`. No registered rule currently emits it. The demotion path is
tested with a deliberately ERROR-severity T3 fixture finding so the override is
not a coincidence.

== Verification discipline

* `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`,
  `cargo test --workspace`, a release build and `tests/e2e.sh` are CI gates.
* The e2e suite executes the actual binary, asserts the ADR-0005 exit matrix,
  scans a known-answer positive corpus, checks every rule's own negative corpus,
  and must fail against a stub binary.
* The falsifier gate loads each positive and negative fixture, rejects a
  tree-sitter error-recovered tree, and refuses empty corpora.
* JSON/SARIF golden tests pin key order and shapes. The SARIF schema validator
  is paired with a mutant that corrupts an enum field, so a validator that
  accepts everything cannot pass vacuously.
* Documentation drift has its own mutant: a fake `--flag` appended to USAGE
  must make `tests/doc_drift.sh` fail.

== Known gaps and honest notes

[cols="2,4",options="header"]
|===
| Gap | Detail

| SMT and machine-checked proofs
| No backend integration, proof artefact or proof-checking CI gate exists in
this workspace. Finite-domain convergence arguments and tested transfer
functions are not a proof of source-to-model correspondence or soundness.

| Source-derived T2 typestate
| ADR-0003 is ratified but no rule walks the CFG with extracted protocol
  events. `pons trace` checks explicit traces only.

| T3 speculative rules
| Plumbing exists; rules 13–15 do not. The `--no-speculative` flag is therefore
  a no-op until those rules land, though its filtering path is implemented.

| Optional adapters
| `challenge`, `extract`, `spell` and `search` are explicitly planned. `doctor`
  reports presence only.

| Encoded legacy corpora
| Latin-1 fallback preserves line structure but makes byte offsets
  artifact-relative only after a decode map. Current SARIF omits those offsets
  rather than lie; EBCDIC/CP037 and fixed-record encodings are future work.

| Statistical proof
| No labelled external corpus precision/recall study or confidence interval has
  been run on this branch. `docs/EXNOVATION-ROADMAP.adoc` defines the required
  protocol before any production-precision claim.

| Two ADRs numbered 0005
| `0005-cli-exit-code-contract.adoc` is normative; `0005-rookie-scanner-development.adoc`
  is now marked historical/superseded. Renumbering remains an owner decision.
|===

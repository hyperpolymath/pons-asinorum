= Vendored schemas: provenance

This directory holds third-party schema documents used by pons's own tests.
They are *vendored verbatim* and must never be edited, reformatted or given an
SPDX header: a schema that differs by one byte from the published one no longer
proves what the test claims it proves.

Used by `crates/pons-core/src/report/sarif.rs` to validate rendered output
against the real SARIF 2.1.0 schema. It is bundled rather than fetched so the
test suite is hermetic, and the `jsonschema` dev-dependency is built with
`default-features = false` precisely so the validator *cannot* reach the
network — a validator that can make HTTP requests is supply-chain surface for
no gain when the schema is self-contained.

To refresh it, re-fetch from the upstream URL, record the new hash here, and
re-run the suite: a schema bump that silently changes what is accepted is
exactly the drift this table exists to make visible.

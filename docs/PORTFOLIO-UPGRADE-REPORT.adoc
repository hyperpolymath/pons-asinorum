= Pons PHP/WordPress upgrade — measured implementation report
:toc:

Date: 25 October 2026. Tested source: `bea5bd60ef5dd3cc644f4cb409396624e156f279`. Baseline:
`c4394f8eea10abbb6b2440139a291fd6370eb03d`. This report records a bounded
implementation, not completion of a universal PHP/security verifier. Code was
prepared on `codex/php-coverage-upgrade`; no main-branch merge or release tag was
performed. The later evidence-only commit does not change the tested code.

== Implemented

* Inventory before adapter selection, explicit unsupported/excluded/failed
  outcomes, no-input exit 2, required-language gates, parser versions, byte digests,
  transcoding disclosure and actual CLI execution status.
* Native PHP AST parsing and three registered rules: empty security functions,
  literal includes, and bounded intraprocedural context-specific may-flow.
* Function-local CFG blocks, branch joins, early exits and loop fixed points;
  opaque unknown scopes are reported. Existing Python dataflow remains separate.
* The exact Praxis nested-branch regression and the intentional async Wharf
  accept-loop control. The original Praxis finding actually covered the trailing
  comment, not an unreachable sibling branch. Relative `__DIR__` resolution also
  has an absolute-versus-relative regression test.
* Strict explicit-event protocol models for transfer ordering, replay/expiry,
  session/artifact/policy binding, signature/root requirements and durable commit.
  Framing and prepared-statement policy reference models have conformance tests.
* Ten language-neutral portfolio model triplets (vulnerable, corrected, similar
  safe), including authorization/publication, bootstrap, parse-result handling,
  encoding/hash identity, atomicity, gateway ownership, and request-state lifetime.
* Versioned JSON schemas, evidence records/fingerprints, malformed-report
  rejection, mandatory scoped suppression metadata and consumer examples.

== Labelled corpus accuracy

registered source rules. Precision = 1.0 and recall = 1.0 on this corpus only.
Corrected controls are included among negatives. The ten protocol-model triplets
are a separate conformance corpus, not extra source-analysis true positives.
No representative, independently labelled real-world portfolio corpus exists
here, so real-world precision/recall remains unknown. The suite was built around
known reduced cases and must not be marketed as a general 100% accuracy score.

== Reproduction and evidence

Checkout the exact baseline and tested source commits in separate worktrees;
build each with `cargo build --release --locked`, keeping separate binary copies.
Checkout the five commits in portfolio-summary.json with clean working trees.
For each recorded target path run the recorded binary with
`scan TARGET --format json --fail-on-skips`, preserving stdout, stderr and the
exit status. The summary supplies all commands, input commits and SHA-256 report
hashes. On Linux, collect wall time and wait4 ru_maxrss, or use GNU time's elapsed
and maximum-resident-set fields; allow for launcher overhead when comparing.

Run `cargo test --workspace --locked`, `cargo clippy --workspace --all-targets --
-D warnings`, `cargo fmt --all --check`, `bash tests/e2e.sh` and
`bash tests/doc_drift.sh`. Run `tests/mutation_smoke.sh` only from a detached
disposable worktree with PONS_MUTATION_DISPOSABLE and PONS_MUTATION_LOG_DIR set.
Its per-mutant timeout is 90 s. Parser size bounds are documented in the migration.

== Remaining work and acceptance limits

. Resolve Composer autoloading, includes, namespace names, traits, references,
  callback captures and WordPress hook dispatch incrementally, with falsifiers.
. Extend PHP CFG/dataflow through exception/finally, richer loops, short-circuit
  side effects and context-aware template output; never treat opaque as safe.
. Add real source-to-event/instrumentation adapters for Wharf and the portfolio
  contracts, backed by runtime verification/durability evidence. The present
  models accept producer premises; they do not establish those premises.
. Complete and independently test panic-attack/Sanctify/Wharf CI consumers of
  contract 1.0.0. Schemas and examples are supplied; those repositories were not
  modified in this task. Correlated heuristics remain correlated.
. Obtain independently labelled real-world source cases and extend long-running
  grammar fuzzing, process-isolated hard resource budgets and sustained load/
  memory tests. Current limits do not prove immunity to all adversarial inputs.
. Implement genuine Haskell and Elixir adapters after PHP. Filename inventory
  and language-neutral fixtures are not language support.
. Address the separate legacy KYAML workflow-style check without weakening it.
  Do not tag a release or claim the full original programme is complete solely
  because local implementation tests pass.

No target application was executed, no live exploit was attempted, and no PHP
runtime deployment was inspected or certified. The PHP C-engine incidents require
separate runtime patch/configuration evidence.

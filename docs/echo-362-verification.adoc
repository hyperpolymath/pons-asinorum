== Scope and correction

The baseline is PONS `b9ab55c6973514a731c7659a2fbee21b5037b1ef`.
The source reproducer is echo-types `ebde9ac4e1a9f115b441c642c82aced1316c5983`,
`docs/echo-types/prototypes/warrant_debugger_prototype.jsx`.
Its valid SVG keyword attribute `in="SourceGraphic"` fails with JavaScript
grammar 0.25.0. The compatible 0.23.1 grammar parses that file without source
rewriting or accepting recovered syntax-error trees. This is a deliberate
compatibility pin, not a claim of support for newer grammar-only syntax.
The shared tree-sitter core and TypeScript/TSX grammar remain unchanged.

When every supported source fails parsing, the report now says `partial`,
not `no-applicable-input`. Report validation independently rejects the old
misclassification. Unsupported Agda inputs remain explicitly unsupported;
this repair does not add an Agda analyser or constitute browser execution.

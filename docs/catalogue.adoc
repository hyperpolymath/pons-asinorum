= Pons rule catalogue

Generated by `pons catalogue`; change the registry, then regenerate.

Rules state their evidence and counter-condition below. PROTOCOL resource arithmetic is conditional on an explicit contract and a completed literal loop. Full CFG/dataflow and inferred source typestate remain unimplemented.

== div-by-literal-zero

* Division or remainder uses a literal zero divisor
* Evidence: `T0` / `Heuristic`; severity: `Warn`
* Languages: python, javascript, typescript, tsx, rust
* Counter-condition: Floating-point infinity/NaN, operator overloads or an intentional failure test may be deliberate.

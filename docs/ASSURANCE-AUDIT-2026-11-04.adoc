== Descriptor counterexample

The former negative `read-before-init/correlated_guard.py` repeats
`self.name is not None`. Python descriptors may return None on the first access
and a value on the second. With MonsterAddName bound to a harmless function,
executing that specimen raises UnboundLocalError before the call.

The exact original specimen is retained in `positive/attribute_guard.py`.
The corrected negative snapshots `self.name` into a local once. The optimisation
now refuses attribute guards, and finding evidence states that abstract CFG
paths may be infeasible. This does not close general path-sensitivity issue #47,
exception modelling or the other limits of the remaining plain-name pruning.
